- **仓库地址**：https://github.com/hyxs1492/blog
- **技术栈**：Astro + Three.js（粒子背景）+ Content Collections（Markdown 文章）

## 一、常用命令

在项目根目录（`blog/`）下执行：

```bash
npm install      # 首次或换电脑后：安装依赖
npm run dev      # 本地预览，默认 http://localhost:4321/blog/
npm run build    # 构建静态站点到 dist/
npm run preview  # 本地预览构建结果
```

发布（推送后 GitHub 会自动构建部署，约 1 分钟）：

```bash
git add -A
git commit -m "更新内容"
git push
```

> 部署完成后若浏览器还是旧内容，用 `Ctrl + F5` 强制刷新。

## 三、写一篇新文章

在 `src/content/blog/` 目录新建一个 `.md` 文件，例如 `unity-tips.md`：

```markdown
---
title: '文章标题'
description: '一句话摘要，会显示在卡片和列表里。'
pubDate: '2026-04-01'
tags: ['Unity', '性能优化']
---

正文用 Markdown 编写。

## 二级标题

- 列表
- **加粗**、`行内代码`

```csharp
// 代码块
Debug.Log("Hello");
```
```

- **文件名（去掉 `.md`）就是网址**：`unity-tips.md` → `/blog/unity-tips/`
- `title` / `description` / `pubDate` 是必填；`tags` 可选。
- 英文文件名更稳妥（中文文件名会让网址变成编码后的形式）。

## 四、修改项目（作品集）条目

项目条目存在 `src/content/projects/`，每个 `.md` 一个项目：

```markdown
---
title: '项目名'
description: '项目简介'
image: '/favicon.svg'      # 可选，截图放进 public/ 后写路径
link: 'https://demo...'    # 可选，演示地址
github: 'https://github... ' # 可选，仓库地址
tags: ['Astro', 'Three.js']
featured: true             # true 会出现在「精选项目」区
---
```

> 现有的两个项目是主题自带的示例，可以删掉或改成你自己的。

## 五、部署说明（已配好，一般不用动）

- 仓库里已有 `.github/workflows/deploy.yml`，推送 `main` 分支即自动构建并发布到 GitHub Pages。
- 站点配置在 `astro.config.mjs`：`site` 与 `base`（当前 `base: '/blog'` 对应 `https://<用户名>.github.io/blog/`）。

如果以后想让网址变成根路径（`https://<用户名>.github.io/` 而不是 `/blog/`），需要把仓库改名为 `<用户名>.github.io`，并把 `astro.config.mjs` 的 `base` 去掉。
